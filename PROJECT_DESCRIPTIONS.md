Python Telegram bot for movie and TV subtitles, with TMDb navigation, validated

## LinkedIn

Built SubMate, an asynchronous Python Telegram subtitle bot with explicit domain,
application, and provider boundaries. Implemented movie and episode navigation,
validated SRT handling, failure recovery, stale-button protection, and local
preference persistence. Automated tests cover provider errors and concurrent
requests. Live delivery and production availability remain verification gates.
