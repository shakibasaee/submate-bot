# SubMate profile introduction

Prepared bilingual plain text for the introduction visible before Start:

> زیرنویس فیلم و سریال در تلگرام. برای شروع Start را بزنید.
> Movie & TV subtitles in Telegram. Tap Start.

This text is prepared for BotFather; it has not been applied to the public bot
profile by this change. Profile viewing alone does not create a new welcome
message. The welcome runs after the user presses Start or sends /start, and
continues when they choose the interface language.

On first /start, choose **فارسی 🇮🇷** or **English 🇬🇧**. Later /start messages use
the stored interface preference and the sender's current Telegram first name.
Change interface language using /settings or About SubMate → Settings.
Subtitle language remains a separate preference, changed through /language or
the Subtitle language home action. Display names are escaped and are not stored.
